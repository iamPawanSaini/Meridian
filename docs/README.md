# docs

All project documentation. Common criterion C5 requires every task to update the docs here.

| Path | Contents |
|---|---|
| `TASKS.md` | The full project task plan (source of truth for scope and acceptance criteria) |
| `PROGRESS.md` | Status board for T00 to T33 |
| `TRACEABILITY.md` | Requirement to task to test case to evidence |
| `architecture/` | Solution and technical design, diagrams, `openapi.yaml`, naming check |
| `adr/` | Architecture decision records `ADR-000x-*.md` |
| `specs/` | `rules.md` (scoring rules with IDs), data model, data sources |
| `design/` | Design tokens and theme (T21a) |
| `standards/` | Coding standards and review checklist (T04a) |
| `tasks/Txx/` | `plan.md` and `review.md` for each task |
| `tests/` | `master-test-plan.md`, `Txx/test-cases.md`, `Txx/test-report.md`, `defects.md` |
| `runbooks/` | Local setup, deploy, restore, incident |
| `process/` | `WORKFLOW.md`: how agents and commands run the per-task loop |
| `templates/` | Templates for plan, review, test cases, test report, defect, ADR, runbook |
